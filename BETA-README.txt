LEXICAL WORLDS — PASSPORT BETA 1.0

START HERE
1. Open Index.html in a browser.
2. Student name/avatar are controlled in js/student-data.js.
3. Add or change the three Next Moves in STUDENT.nextMoves.
4. To connect an activity later, put its URL in the move's link field.
5. Calendar buttons open a Google Calendar event using the move title and estimated minutes.

IMPORTANT
- Beta is intentionally standalone: it does NOT fetch JSON, so it works when Index.html is opened directly.
- Unfinished systems remain visually present but are marked BETA / NOT ACTIVE YET.
- Do not delete the empty JS architecture files; they are placeholders for later systems.
- When we move beyond beta, student-data.js can be replaced with a proper data source without redesigning Index.html.
